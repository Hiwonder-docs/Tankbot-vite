5.6.1 Introduction to WonderLLM Offline Vision ​

5.6.1.1 Module Introduction ​

WonderLLM is a large AI model module with a built-in ESP32-S3 high-performance chip. The module integrates a 2 MP high-definition camera, a microphone, a high-definition display, a speaker, and a CI1302 voice recognition chip, providing deep integration of text, voice, and vision models.

This module is easy to operate and is often used with robots, giving them a "super brain" that enables deep understanding of commands. It provides advanced perception, reasoning, and action capabilities, delivering flexible and natural human-robot interaction.

5.6.1.2 Introduction to Working Modes ​

The WonderLLM module supports two working modes: offline mode and online mode. These two modes have different functions, and the corresponding firmware must be flashed for each mode. The working mode used in this chapter is the offline mode.

5.6.1.2.1 Offline Mode ​

In offline mode, the module captures images through the built-in camera module and processes the image data using the ESP32-S3 microcontroller. The module supports image transmission, color recognition, face detection, and other functions. Data can be transmitted through multiple communication protocols.

5.6.1.2.2 Online Mode ​

Online mode supports voice interaction with large AI models and adopts a passphrase-based wake-up mechanism. A wake word must be spoken to wake WonderLLM before human-machine interaction can begin. The default wake keyword is Hello Hiwonder.

After the module recognizes the wake word, the buzzer emits a single beep, after which interaction can begin. The module supports communication in English, and automatically identifies and switches the language based on the detected speech. If no speech is recognized within 1 minute, the module enters sleep mode and requires re-activation for subsequent use.

5.6.1.3 Interface Description ​

5.6.1.4 Precautions ​

  1. Ensure the module input power is at least 5 V and 2 A, otherwise image ripples may appear.

  2. The factory default includes a large AI model function. To change the function, the corresponding program must be flashed.

  1. The WonderLLM vision module communicates with the ESP32 controller via IIC communication to enable color recognition. The colorDetect() function sequentially reads the detection results for red, green, and blue. When the width of a detected color, which is the third byte, is greater than 0, the corresponding color index is returned, where 1 is red, 2 is green, and 3 is blue. If no color is detected, 0 is returned.
cpp
int HW_WonderLLM_Vision::colorDetect(void)
{
  uint8_t color_info[3][4];
  int num = iic->wireReadDataArray(WonderLLM_Vision_ADDR,0x00,color_info[0],4);
  if((num == 4) && (color_info[0][2] > 0)) //if w value greater than 0, color 1 recognized
  {
      return 1;
  }
  num = iic->wireReadDataArray(WonderLLM_Vision_ADDR,0x01,color_info[1],4);
  if(num == 4)
  {
    if(color_info[1][2] > 0) //if w value greater than 0, color 2 recognized
    {
      return 2;
    }
  }
  num = iic->wireReadDataArray(WonderLLM_Vision_ADDR,0x02,color_info[2],4);
  if(num == 4)
  {
    if(color_info[2][2] > 0) //if w value greater than 0, color 3 recognized
    {
      return 3;
    }
  }
  return 0;
}

  1. In the loop() function, the program controls the color tracking process using a state machine. It first enters the case 0 branch for target detection, calls the cam.color_position() function to obtain the red color position data, and stores it in the color_info array. After successful detection, it enters the case 1 branch for tracking control.
cpp
void loop() {
  switch(fsm_state)
	{
	  case 0:
      // get color coordinates
      if(cam.color_position(color_info,RED))
      {
        fsm_state = 1;
      }
		  break;

  1. In the case 1 branch, the offset between the target color position and the screen center position is calculated. The X-axis offset is mapped from [-120, 120] to [-2, 2] using the map function, accumulated into x_inc_total, and limited to the range [-375, 375]. The Y-axis offset is mapped from [-120, 120] to [-1.5, 1.5], accumulated into y_inc_total, and limited to the range [-480, 50]. The arm.knot_run() function is called to control the servo movement. Servo ID 6 controls X-axis tracking, and its target position is calculated as SERVO6_RESET_DUTY minus x_inc_total. Servo ID 3 controls Y-axis tracking, and its target position is calculated as 220 minus y_inc_total. After a 30 ms delay, the state machine is reset for the next round of detection and tracking.

    cpp
    	  case 1:
      // robotic arm movement
      // calculate the offset of the robotic arm, and map it to get the target position of the robotic arm
		  x_bias = color_info[0] - CENTER_X;
      y_bias = color_info[1] - CENTER_Y;
      if(abs(x_bias) > 8){
        x_inc_total += 1 * map((float)x_bias, -120.0f, 120.0f, -2, 2);
        x_inc_total = x_inc_total < -375 ?-375 : x_inc_total > 375 ? 375: x_inc_total;
        arm.knot_run(6, (int)(SERVO6_RESET_DUTY - x_inc_total), 10);
      }
      
      if(abs(y_bias) > 8){
        y_inc_total += 1 * map((float)y_bias, -120.0f, 120.0f, -1.5, 1.5);
        y_inc_total = y_inc_total < -480 ? -480 : y_inc_total > 50 ? 50: y_inc_total;
        arm.knot_run(3, (int)(220 - (int)y_inc_total), 10);
      }

		  delay(30);
		  fsm_state = 0;
		  break;
	}
}
  1. The WonderLLM vision module exchanges data with the ESP32 main controller via IIC communication to implement color position detection. The color_position() function reads 4 bytes of color position data (x, y, w, and h) from the vision module. When the width value is greater than 0, a color is detected. The function returns true and stores the position data in the color_info array.

  {
    return true;
  }
  return false;
}

{

  int num = iic->wireReadDataArray(WonderLLM_Vision_ADDR,0x01,face_info,4);
  if((num == 4) && (face_info[2] > 0)) // receive the recognized face's x,y,w,h values
  {
      return true;
  }
  return false;
}

  1. In the loop() function, the program controls the line-following process through a state machine. In the case 0 state, the cam.color_position(RED) function is called to obtain the position information of the red line. After successful detection, the program switches to the case 1 state for chassis control.

void loop() {
  switch(fsm_state)
  {
    case 0:
      // get position of red line
      if(cam.color_position(RED))
      {
        fsm_state = 1;
      }
      break;

    case 1:
      // Calculate offset and control chassis

  1. When the absolute offset value is greater than 1, the map function maps the X-axis offset from [-80, 80] to a steering speed in the range [-0.35, 0.35]. If the steering speed is greater than 0.05 or less than -0.05, the robotic car moves forward at a speed of 50 and performs a steering correction. Otherwise, the robotic car moves straight forward at a speed of 50. After completion, the state machine is reset to prepare for the next round of detection.

  1. The custom map function implements numeric mapping, linearly mapping the input value x from [in_min, in_max] to [out_min, out_max]. This function is used to convert visual offsets into chassis steering speed.
cpp
static float map(float x, float in_min, float in_max, float out_min, float out_max)
{
    return out_min + (x - in_min) * ((out_max - out_min) / (in_max - in_min));
}
  1. The WonderLLM vision module exchanges data with the ESP32 main controller through IIC communication, implementing the color position detection function. The color_position() function reads 4 bytes of color position data (x, y, w, h) from the corresponding register according to the specified color index RED=1. A width value greater than 0 indicates that a color is detected, and the data is then stored in the ColorResults array.
cpp
bool HW_WonderLLM_Vision::color_position(uint8_t ColorIndex)
{
  int num = iic->wireReadDataArray(WonderLLM_Vision_ADDR, ColorIndex - 1, ColorResults[ColorIndex - 1], 4);
  if((num == 4) && (ColorResults[ColorIndex - 1][2] > 0)) //receive recognized color x,y,w,h values
  {
    return true;
  }
  return false;
}
