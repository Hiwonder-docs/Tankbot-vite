5.5 AI Voice Project Course ​

5.5.1 WonderLLM Offline Voice Introduction ​

5.5.1.1 Offline Voice Interaction Description ​

5.5.1.1.1 Module Introduction ​

WonderLLM voice interaction is based on the CI1302 chip for speech recognition and voice broadcasting. It supports offline NN acceleration computing and speech signal processing acceleration hardware. Recognition results are derived through deep noise reduction and neural network model analysis.

The CI1302 chip incorporates a brain neural network processor core (BNPU), supporting offline NN acceleration and hardware-accelerated voice signal processing. The CPU clock frequency reaches up to 220 MHz, enabling offline far-field voice recognition. The chip features 2 MB of built-in FLASH storage and supports up to 300 command words.

This module features simple operation and excellent speech recognition performance, making it widely applicable in fields such as smart homes, conversational robots, educational robots, and in-vehicle dispatch terminals.

5.5.1.1.2 Work Principles ​

This module uses wake word mode for activation. The wake word must be spoken to activate the module, and recognition is available only after activation. The default recognition language is English, and the English wake word is Hello Hiwonder. If no speech is recognized within 15 seconds, the module enters sleep mode and must be re-awakened before the next use.

After the CI1302 chip recognizes the corresponding voice entry, it sends the instruction associated with that entry to the IIC chip and provides broadcast feedback. The IIC chip stores the received voice instruction and transmits it via the IIC slave protocol. Specific voice entries are listed in Command Word Broadcast Protocol List in the same path as this document.

5.5.1.2 Module Wiring ​

Module Wiring: As shown in the figure below, connect the module to any I2C interface in the red frame of the servo controller before running the program in this section.

5.5.1.3 Precautions ​

  1. The module must be powered with 5 V. Otherwise, the module will be damaged.
  2. The operating environment should be quiet. A noisy environment affects recognition performance.
  3. Commands should be spoken loudly and at a moderate pace. The distance from the module should be kept within 5 meters.

'Shake head' with code 0x1E makes the servo ID 6 of the robotic arm swing left and right to simulate a head-shaking action.

unsigned char result;
static bool have_move = true;

result = hwsensor.rec_recognition();  //get voice recognition module data
if(result)
{

  Serial.println(result);

  if(result==0x1A) //hello
  {
    arm.coordinate_set(15,0,14,-45,-90,90,500);
    delay(600);
    arm.claw_set(30,200);
    delay(300);
    arm.claw_set(90,200);
    delay(300);
    arm.claw_set(30,200);
    delay(300);
    arm.claw_set(90,200);
    delay(300);
    arm.coordinate_set(15,0,2,-40,-90,10,1000);
    delay(1500);
  }
  else if(result==0x1B) //introduce yourself
  {
    arm.action_run(4, 1);
    arm.coordinate_set(15,0,2,-40,-90,10,1000);
    delay(1500);
  }
  else if(result==0x1D) //walk two steps
  {
    differentials_chassis_run(20.0f, 0.0f);
    delay(1500);
    differentials_chassis_run(0.0f, 0.0f);
    delay(500);
  }
  else if(result==0x1E) //shake head
  {
    arm.knot_run(6,700,500);
    delay(600);
    arm.knot_run(6,300,500);
    delay(600);
    arm.knot_run(6,700,500);
    delay(600);
    arm.knot_run(6,300,500);
    delay(600);
    arm.knot_run(6,500,500);
    delay(600);
    arm.coordinate_set(15,0,2,-40,-90,10,1000);
    delay(1500);
  }
}
delay(50);
  1. The WonderLLM offline voice mode performs data exchange with the ESP32 controller via I2C communication to implement the voice recognition function. This function reads the recognition result from the module's ASR_RESULT_ADDR register, retrieves the recognition result value through I2C communication, and returns it.
cpp
uint8_t ASR_MOUDLE::rec_recognition(void)
{
  if(iic != nullptr){
    uint8_t result = 0;
    iic->wireReadDataArray(I2C_ADDR_RESERVE , ASR_RESULT_ADDR ,&result,1);
    return result;
  }
  return 0;
}

After a 2-second wait, "Hello, welcome" is broadcast, corresponding to 0x0F. After a 3-second wait, "Red" is broadcast, corresponding to 0x2A. After a 2-second wait, the cycle repeats. Here, the ASR_CMDMAND parameter is used for broadcasting command words, and the ASR_ANNOUNCER parameter is used for broadcasting announcement words. According to the command word and announcement word protocol list, 0x1B corresponds to the "Introduce yourself" function, 0x01 corresponds to the "Forward" function, 0x0F corresponds to "Hello, welcome", and 0x2A corresponds to "Red".
cpp

delay(5000);
asr.speak(ASR_CMDMAND , 0x01);
delay(2000);
asr.speak(ASR_ANNOUNCER , 0x0F);
delay(3000);
asr.speak(ASR_ANNOUNCER , 0x2A);
delay(2000);
  1. The WonderLLM offline voice mode exchanges data with the ESP32 controller through IIC communication, thereby implementing the voice broadcast function. This function writes a broadcast command to the ASR_SPEAK_ADDR register of the module, causing the module to broadcast the specified voice content. The cmd parameter specifies the broadcast type, where 0x00 indicates a command word and 0xFF indicates a broadcast word. The id parameter specifies the specific broadcast content ID.
cpp
void ASR_MOUDLE::speak(uint8_t cmd , uint8_t id)
{
  if(iic != nullptr){
    if(cmd == 0xFF || cmd == 0x00)
    {
      send[0] = cmd;
      send[1] = id;
      iic->wireWriteDataArray(I2C_ADDR_RESERVE , ASR_SPEAK_ADDR , send , 2);
    }
  }
}

  1. In the loop() function, the program calls the ult.GetDistance() function to obtain the distance value from the ultrasonic sensor and determines whether an obstacle is present based on the distance. When the distance is in the range of 20-200 mm, the ult.Color() function is called to set the LED to red with an RGB value of 255,0,0 and to play a voice reminder with the content ID 0x05. When no obstacle is present, the LED is set to green with an RGB value of 0,255,0. The program checks the distance every 250 ms and outputs the distance value through the serial port for debugging.

  1. The ultrasonic module communicates with the ESP32 controller via IIC communication to achieve distance measurement and LED color control. The GetDistance() function reads 2 bytes of distance data in millimeters from register address 0 of the module, and returns the distance value. The Color() function is used to set the LED colors on both sides of the ultrasonic module. The parameters r1, g1, b1 and r2, g2, b2 represent the RGB color values of the left and right LEDs respectively.
cpp
uint16_t Ultrasound::GetDistance()
{
  uint16_t distance;
  iic->wireReadDataArray(ULTRASOUND_I2C_ADDR, 0,(uint8_t *)&distance,2);
  return distance;
}
