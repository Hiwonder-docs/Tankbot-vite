## 5.1.1 Arduino IDE Installation and Usage

### 5.1.1.1 Arduino IDE Installation and Interface Introduction

Arduino IDE is software specifically designed for Arduino microcontrollers and offers powerful functionality. Regardless of the version, the installation process remains the same. This section uses the Windows version of Arduino IDE 2.2.1 as an example for explanation.

> [!NOTE]
>
> **The installation method for the Mac version can be found in this section's table of contents.**

1) Locate the [**Arduino IDE Installation Package**]() in the same directory as this document, as shown below, and double-click to open it. To download the latest version of the software, visit the Arduino official website [**<u>https://www.arduino.cc/en/software</u>**](https://www.arduino.cc/en/software).

    <img src="../_static\media\chapter_4\section_1\01\image1.png" style="width:0.98403in;height:1.15069in" class="common_img" />

2) Click **I agree** to proceed with the installation.

<img src="../_static\media\chapter_4\section_1\01\image2.png" style="width:5.31528in;height:3.8375in" alt="企业微信截图_17032376944987" class="common_img" />

3) Select the default checked option and click **Next** to proceed to the next step.

<img src="../_static\media\chapter_4\section_1\01\image3.png" style="width:5.31528in;height:3.85833in" alt="2" class="common_img" />

4) Click **Browse...** to select the installation path, and then click **Install** to start installation.

<img src="../_static\media\chapter_4\section_1\01\image4.png" style="width:5.31528in;height:3.83889in" alt="3" class="common_img" />

5. Wait for the software installation to complete.

<img src="../_static\media\chapter_4\section_1\01\image5.png" style="width:5.31528in;height:3.83125in" alt="4" class="common_img" />

> [!NOTE]
>
> **If the installation process prompts that a chip driver needs to be installed, check "Always trust software from Arduino LLC (A)", and then click Install.**

6) After installation is complete, click **Finish**.

<img src="../_static\media\chapter_4\section_1\01\image6.png" style="width:5.31528in;height:3.80486in" alt="5" class="common_img" />

### 5.1.1.2 Arduino IDE Usage Instructions

* **Arduino IDE Interface Settings**

1) Change the interface language: In the Arduino IDE interface, select **File** > **Preferences**. In the pop-up window, select the desired language from the **Language** option, then click **OK**.

    <img src="../_static\media\chapter_4\section_1\02\image1.png" style="width:5.76389in;height:4.19653in" class="common_img" />

2) By selecting **File > Preferences**, settings such as the project file path, editor font size, and color theme can be modified in the pop-up window.

    <img src="../_static\media\chapter_4\section_1\02\image2.png" style="width:5.76389in;height:3.81319in" class="common_img" />

* **Arduino Program Upload**

1) The example code that prints **hiwonder** is used here for illustration. Open the **Demo.ino** example program by double-clicking it in the [**Demo**]() folder located in the same directory as this document.

    <img src="../_static\media\chapter_4\section_1\02\image3.png" style="width:5.76389in;height:3.37986in" class="common_img" />

2) Connect the ESP32 controller to the computer via a data cable.

    <img src="../_static\media\chapter_4\section_1\02\image4.png" style="width:5.76389in;height:4.01736in" alt="开源6路舵机控制器接ESP32再连接电脑" class="common_img" />

3) In the **Select Board** option, find the development board corresponding to Arduino. **The COM port is not unique. The COM number can be checked in Device Manager. COM6 is used here as an example.**

    <img src="../_static\media\chapter_4\section_1\02\image5.png" style="width:5.76389in;height:3.69028in" class="common_img" />

4) Click the <img src="../_static\media\chapter_4\section_1\02\image6.png" style="width:0.42708in;height:0.39583in"  class="inline-icon" /> button to compile the program and verify whether the program has any syntax errors or other issues.

    <img src="../_static\media\chapter_4\section_1\02\image7.png" style="width:5.76389in;height:3.60972in" class="common_img" />

5)  After successful compilation, click the **<img src="../_static\media\chapter_4\section_1\02\image8.png" style="width:0.40625in;height:0.38542in"  class="inline-icon" />** button to upload the program to the ESP32 controller.

    <img src="../_static\media\chapter_4\section_1\02\image9.png" style="width:5.76389in;height:3.60972in" class="common_img" />

6) After the upload is complete, click <img src="../_static\media\chapter_4\section_1\02\image10.png" style="width:0.36458in;height:0.36458in"  class="inline-icon" /> to open the Serial Monitor, where the message **hiwonder** is printed.

    <img src="../_static\media\chapter_4\section_1\02\image11.png" style="width:5.76389in;height:3.37986in" class="common_img" />

* **Library File Import**

To run the program, the required **u8g2** and **LeArm_Kinematics_lib library** files need to be imported. The procedure is described below, with the **u8g2** library used as an example to demonstrate the import steps.

1) In the Arduino IDE, select **Sketch > Include Library > Add .ZIP Library**.

    <img src="../_static\media\chapter_4\section_1\02\image12.png" style="width:5.76667in;height:3.81597in" class="common_img" />

2) In the pop-up window, find **u8g2.zip** in the [**ArduinoIDE Installation Package**]() folder, which is in the same directory as this document, and click Open.

    <img src="../_static\media\chapter_4\section_1\02\image13.png" style="width:5.13542in;height:0.32292in" class="common_img" />

3) If the following prompt appears, the library file installation is complete.

    <img src="../_static\media\chapter_4\section_1\02\image14.png" style="width:5.22917in;height:0.45833in" class="common_img" />
